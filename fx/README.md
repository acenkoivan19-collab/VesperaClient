# Vespera FX

Дополнение к Vespera Client: новые визуалы как обычные модули клиента. Отдельный мод (`vespera_fx`),
ставится **рядом** с `vespera-client` — сам клиент не заменяет и его модули не трогает.

Скачать (всегда последняя сборка):
https://github.com/acenkoivan19-collab/VesperaClient/releases/download/dev-build/vespera-fx.jar

## Что добавляет (всё по умолчанию выключено)

| Модуль | Раздел | Что делает |
|---|---|---|
| Aura | Visuals | Пламя, неоновые кольца, вихрь или щит вокруг игрока |
| Item Glow | Visuals | Свечение / луч / кольцо у выпавших предметов, цвет по редкости |
| Projectile Trails | Visuals | Светящиеся следы за стрелами, жемчугом, зельями, трезубцами |
| Block Effects | Visuals | Осколки при ломании, вспышка при установке, волна взрыва |
| Screen Effects | Visuals | Виньетка, пульс при низком HP, вспышка урона, линии скорости |
| Render Quality | Visuals | Авто-качество: эффекты упрощаются, когда FPS падает |
| Totem Pop | Combat | Взрыв частиц и счётчик ×N при срабатывании тотема |
| Hit Marker | Combat | Метка попадания у прицела: крит, добивание |

Правило «не читы» соблюдается: эффекты на других игроках и предметах — только при прямой видимости.

## Как это работает

- Модули добавляются в `ModuleManager` клиента в `onInitializeClient` — до загрузки конфига
  (`CLIENT_STARTED`), поэтому они есть в меню и сохраняют настройки.
- Если в клиенте уже есть модуль с таким же именем, модуль FX пропускается (без конфликта).
- Используется только публичный API клиента: `Module`, `HudModule`, `ModuleManager`, настройки,
  `Draw`, `WorldDraw`, `Projection`, `Theme`, `Fonts`.
- Сборка: `gradle -p fx build` после сборки основного клиента (нужен `build/devlibs/*-dev.jar`).
