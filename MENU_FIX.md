# Фикс и доработка меню

## 1. ПКМ-панель больше никогда не пустая
`ui/ModuleSettingsPanel` переписан. Сверху вниз в панели идут:
- название;
- полное описание (`Module.about()`, переносится по строкам, без обрезки);
- тумблер «Включён»;
- превью, если оно есть;
- «Масштаб/Прозрачность» для HUD;
- режимы: чипы с подписью-пояснением (`ChoiceSetting.hints`);
- цвета: палитра, «T» (цвет темы) и шкала оттенка;
- слайдеры;
- переключатели;
- кнопки «Сбросить» и «Сбросить позицию» (последняя только у HUD).

Если у модуля нет своих опций, панель всё равно показывает описание и тумблер.

## 3. Минимализм
- Карточки модулей (`ModuleCard`) теперь плоские: без свечения, без акцентной обводки и без цветной иконки.
- `Toggle` больше не светится, акцентный цвет у него появляется только во включённом состоянии.
- В `ClickGuiScreen` у панели, логотипа, плашек версий, кнопки «Редактор HUD» и скроллбара теперь нейтральные цвета.
- Активная категория — плоская плашка с акцентной полоской слева.
- Под шапкой меню добавлен тонкий разделитель.
- В поле поиска (`SearchField`) нет свечения при фокусе, рамка нейтральная.
- Новых цветов не добавлено. Акцент остаётся только у включённых тумблеров, активной категории и выбранных элементов в ПКМ-панели.

## 4. Новые HUD-модули (по умолчанию выключены, участвуют в раскладке)
| Модуль | Что показывает |
|---|---|
| Inventory | хотбар и/или рюкзак иконками предметов, прочность |
| Combo | счётчик попаданий с анимацией «pop», полоса окна и рекорд |
| Items Counter | тотемы, яблоки, зачарованные яблоки, жемчуг, стрелы (ряд или столбик) |
| BPS | скорость в блоках/с или км/ч |

TargetHP встроен в Target HUD как режим «Полоса ХП». Остальные элементы старого HUD (fps, coords, cps, armor, direction, session, ram, clock, sprint, server, reach, cooldowns, saturation, pickup, music, keys, potions, watermark) уже были нативными модулями, дублировать их не стали.

## Удалены заглушки
Custom Fog, Particles+, Hotbar, Screenshot+, Discord RPC, Cape, Menu Blur и Custom Font были пустыми тумблерами без кода.
